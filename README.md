# AI EDU — 자율주행 학습·검증 수업 프로그램

고등학교 1–2학년 2·3차시(각 50분)의 프로그램 개발 설계 작업 공간입니다.

- [개발 설계서](docs/development-design-v0.1.md): 수업 요구사항, 화면, 주행 규칙, 데이터, 구조, 검증 계획
- [개발 작업 목록](docs/development-backlog.md): 단계별 산출물과 완료 조건
- [기준 노션 수업안 스냅샷](docs/source-notion-2026-10-26.md): 2026-10-26 확인

현재는 G0 연결 실험, 직접 조작하는 3D 주행, 학생 전처리와 Orange 학습/검증 파일 저장을 구현한 상태입니다. Orange 회귀 트리를 JSON으로 변환하고 실제 브라우저에서 1,214개 입력의 예측이 일치함을 확인했습니다. 주행 계산·전처리는 별도 검증 34개를 통과했습니다. 실제 주행 데이터의 하이퍼파라미터 선정과 전체 수업 흐름은 아직 개발 중입니다.

- [퀘스트 → 장면 회고 → 1분 개념 학습 → 전처리 흐름](simulator/LEARNING-FLOW.md): 기록 전 조작 퀘스트 4개, 주행 후 의도 비교, 결측치·이상치 영상과 개념 확인 뒤 전처리. 자동 검증 42개·브라우저 전체 흐름 확인(2026-10-27).

학생 장비는 Windows 10/11, LG 그램 수준의 내장 그래픽 노트북을 가정합니다. 브라우저에서 가벼운 3D 화면을 실행하고, Orange 학습 모델을 연결하는 방향을 우선 검증합니다. 실제 학교 장비·브라우저 버전은 미확정입니다.

최신 시제품: WebGL 3D 도로에서 연속 가속·브레이크 조작을 지원합니다. [변경 및 실행 방법](simulator/CHANGELOG-3D.md).
