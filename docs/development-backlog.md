# 개발 작업 목록

최신 진행(2026-10-27, 학습 흐름): 기록 전 조작 퀘스트 4개(저장 안 함), 주행 전 기준 선택, 주행 후 장면 다시 보기와 의도 비교 회고, 결측치·이상치 1분 영상과 개념 확인 2문항을 거쳐 전처리로 가는 흐름을 구현·검증했다. 퀘스트 2 막힘·실패 안내·충돌 장면 누락을 고쳤다. 자동 검증 42개, 브라우저 전체 흐름 확인. [상세](../simulator/LEARNING-FLOW.md).

최신 진행(2026-10-27, 전처리): REVIEW-02와 REVIEW-01의 주행 ID 단위 분리 구현·검증. 결측치/이상치 설명, 원본 보존, 학생 판단·사유·취소, JSON 이력 복원, Orange .tab 출력 포함. 계산·전처리 검증 34개 통과 및 브라우저 다운로드/복원 확인. 시나리오 계열 분리·TUNE-01 이후는 남아 있다. [사용법과 증거](../simulator/PREPROCESSING.md). 아래는 이전 진행 이력이다.

최신 변경: 3D 도로·차량·카메라와 즉시 반응하는 가속/브레이크 페달을 연결했다. 직접 조작은 0.02초마다, 모델은 1초마다 적용하며 조작 이력을 보존한다. 자동 검증 18개 및 브라우저 페달 조작 확인. [상세 기록](../simulator/CHANGELOG-3D.md).

최신 진행(2026-10-27): 두 차량 운동·충돌 검출, 직접 조작 2D 화면, 1초/부분 구간 기록, CSV·JSON 다운로드를 추가했다. 계산 검증 16개와 실제 브라우저의 마른/젖은 감속 및 충돌 종료 확인을 완료했다. 초기 학습 CSV는 전처리 전 자료이며 REVIEW·TUNE 작업은 남아 있다. 모형 주행 파일 불러오기 UI는 구현했으나 전체 Orange GUI 전달 경로는 미검증이다.

2026-10-27 진행: 결측치·이상치 개념 설명을 전처리 필수 요구사항에 추가했다. SIM-01 중 단일 차량의 가감속·정지·상한 도달·부분 구간 기록 코어를 구현했다. 두 차량 충돌 및 UI는 미구현이며 아래 초기 상태의 G1 미착수 표기는 이 진행 기록으로 갱신한다. [주행 코어](../simulator/README.md).

상태: G0의 MODEL-01~03을 제한된 범위에서 구현·검증했다. Orange 3.40.0 기본 회귀 트리와 합성 시험 자료 1,214개에서 원본/브라우저 예측 차이 0. GUI 파일 전달·학교 Windows 장비 검증은 미완료다. ENV-01·VIEW-01 및 G1 이후는 미착수. 상세 결과는 [연결 실험](../model-bridge/README.md), 상세 요구사항은 [개발 설계서](development-design-v0.1.md)를 따른다.
