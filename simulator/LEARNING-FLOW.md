# 퀘스트 → 기록 주행 → 장면 회고 → 1분 개념 학습 → 전처리

2026-10-27. 학생이 운전 기준 없이 바로 데이터를 쌓는 문제를 줄이기 위해, 기록 전에 조작 퀘스트를 거치고 기록 후에는 숫자 표보다 장면을 먼저 보게 했다.

```
[퀘스트 1~4] ──(저장 안 함: source=guided_practice)──▶ [기준 선택]
   가속 20km/h / 페달 놓고 속도 유지 확인 / 브레이크 정지 / 앞차 출발 확인 후 따라가기
[기준 선택] ─▶ [기록 주행] ─(종료·충돌)─▶ [장면 회고: 의도·일치·근거·다음 행동]
[장면 회고 완료] ─▶ [1분 영상 + 개념 확인 2문항 정답] ─▶ [전처리]
```

- 퀘스트 판정(`learning.mjs`): 실제 조작 결과(속도·페달·앞차 속도)로만 클리어. 4번은 앞차 출발 전 움직이면 실패.
- 퀘스트 기록은 기록 목록·전처리에 들어가지 않으며, 전처리에 직접 넣어도 `guided_practice`로 잠겨 제외된다.
- 회고 전에는 `전처리 실습` 버튼·기록 화면의 전처리 버튼이 회고 창으로 돌아간다. 개념 확인 두 문항이 맞아야 전처리가 열린다.
- 회고 내용과 주행 전 기준은 학습 목표값을 바꾸지 않고, 전처리 이력의 `learning_context`에만 남는다.

## 이번 세션에서 고친 점

| 문제 | 재현 | 수정 |
| --- | --- | --- |
| 퀘스트 2에서 가속을 살짝 누르면 20km/h로 돌아갈 수 없어 12초 실패까지 막힘 | 브라우저에서 0.3초 가속 후 놓기 → 14초 동안 클리어 안 됨 | 페달을 놓은 순간의 속도가 1.2초 유지되면 클리어 |
| 모든 실패에 "앞차가 출발하기 전에 움직였거나…" 같은 문구 | 퀘스트 1·2·3 실패 시에도 같은 안내 | 퀘스트별 실패 이유(시간 초과·조기 출발·충돌) 안내 |
| 충돌 직전에 브레이크를 밟으면 회고 장면에서 "충돌 직전 장면"이 사라짐 | 제동 0.5초 안에 충돌 → 장면 1개(첫 브레이크)만 표시 | 겹칠 때 충돌 장면을 우선 |

세 경우 모두 수정 전 코드에서 실패하는 테스트를 `learning.test.mjs`에 추가했다. 전체 자동 검증 42개 통과(`test-results.txt`).

## 브라우저 검증 (Chromium, 2026-10-27)

`verify-learning-flow.cjs`, 로그 `results/learning/browser-flow-log.txt`, 화면 `results/learning/flow-0*.png`.

- 퀘스트 1~4 클리어, 4번 조기 출발은 실패 및 이유 표시. 퀘스트 후 기록 수 0, 기록 보기는 "퀘스트를 마친 뒤 기록 주행을 시작하세요."
- 기준 미선택 시 기록 시작 거부. 기록 주행 충돌 시 회고 창 자동 표시, 장면 다시 보기 슬라이더가 저장된 위치를 표시.
- 회고 미완료 상태에서 `전처리 실습` → 회고 창으로 복귀. 네 항목이 모두 있어야 저장.
- 1분 영상 재생 확인(60초, 1280×720). 오답이면 전처리가 열리지 않고, 정답이면 전처리 화면이 열림.
- 전처리의 원본 행 수 = 기록 주행 행 수(7행). 퀘스트 기록은 포함되지 않음. 콘솔 오류 없음.
