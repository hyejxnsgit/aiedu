# 3D 가상 운전 시뮬레이터 — 2026-10-27

## 이번 변경

- Three.js 0.186.1 기반 WebGL 3D 도로·차량·가로수·거리선. 라이브러리 파일은 로컬에 포함하며 런타임 CDN 연결은 없다. 라이선스는 vendor/THREE-LICENSE.txt.
- 차량 뒤에서 보는 시점과 운전자 시점 전환. 실제 차체 위치와 카메라가 같은 물리 좌표를 사용한다.
- 큰 가속/브레이크 페달 또는 ↑/↓, W/S. 직접 운전 입력은 다음 0.02초 계산에서 반영한다. 양쪽 입력이 있으면 브레이크 우선.
- 페달을 놓으면 가감속 0, 현재 속도 유지. 공기저항·엔진 브레이크를 생략한 교육용 단순화다. 스티어링은 일차선 직진 수업 범위에 포함하지 않았다.
- 속도계·차간거리·앞차 속도·브레이크등·정지/재출발 안내. 운전 조작부는 도로와 같은 화면에 유지한다.
- 원래 모델 제안은 1초에 한 번, 직접 운전은 연속 페달. 1초 시작 입력과 실제 변화량은 그대로 유지하되 구간 안의 변경은 control_changes로 보존한다. requested_delta_kmh는 구간 시작 요청이므로 구간 전체의 고정 요청으로 해석하면 안 된다.
- 일시정지·창 이탈·숨겨진 탭에서 페달 입력 해제. 프레임 지연이 0.3초를 넘으면 급격한 시간 따라잡기 대신 일시정지한다.
- 기록은 별도 대화상자에서 확인하고 CSV/JSON 저장. 새 주행을 만들어도 이전 기록은 탭이 열린 동안 보존한다. 영구 저장/복구는 아직 파일 다운로드에 의존한다.

## 검증

`node --test simulator/motion.test.mjs simulator/drive.test.mjs` → 18개 통과.

추가 검증: 구간 중 직접 조작 변경이 즉시 반영됨, 해제 후 속도가 유지됨, 모델 판단은 여전히 1초 동안 고정됨.

실제 브라우저: WebGL 렌더링, 운전 시작, 브레이크 약 1.2초 유지로 속도 30→약 13 표시, 가속 약 1초 유지로 약 13→20 표시, 일시정지 확인. 도로·차량·페달이 동시에 보이는 증거: preview-3d.png. 정확한 입력 구간의 단위 검증은 위 자동 테스트로 수행한다.

## 실행 및 범위

프로젝트 루트에서 `python3 simulator/preview.py` 실행 후 http://127.0.0.1:8766/simulator/ 접속. 기존 8766 서버가 실행 중이면 그대로 사용한다. 파일 변경 후 미리보기 복사본도 갱신하거나 서버를 다시 시작한다. helper는 필요한 파일만 임시 폴더로 복사한다.

본 버전은 작동하는 수업용 주행 시제품이다. 정교한 차량 동역학, 실제 차량 안전 인증, 학생 전처리 UI, 하이퍼파라미터 선정, Orange GUI 전체 전달 과정, 학교 Windows 성능 시험은 완료된 것으로 간주하지 않는다.
