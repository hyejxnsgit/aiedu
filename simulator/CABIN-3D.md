# 2차시·3차시 구분과 3D 차량 실내 (React Three Fiber)

2026-10-27.

```
[차시 선택 화면: 학습 목표·흐름]
   ├─ 2차시 (#s2) → 운전대 있는 실내, 운전대 아래 양옆에 브레이크·가속 → 퀘스트 → 기록 → 회고 → 영상 → 전처리
   └─ 3차시 (#s3) → 운전대 없는 실내 → 모델 JSON 불러오기 → 자동 주행 (학생 회고 창은 열지 않음)

app.mjs ── new World(canvas) ──▶ world.jsx (createRoot(canvas) + <Scene/>)
          render(d) ──▶ d 저장 + invalidate() ──▶ useFrame에서 차량·카메라·화면을 직접 갱신
```

## 실행

```
cd ~/AI-EDU/simulator
npm install          # 처음 한 번 (react, react-dom, @react-three/fiber, @react-three/drei, three, vite)
npm run dev          # 개발용: http://127.0.0.1:8766/ (수정 즉시 반영)
```

Node가 없는 학교 노트북에서는 미리 빌드한 `dist/`를 `python3 preview.py`로 제공한다(같은 주소). 코드를 고친 뒤에는 `npm run build`로 dist를 다시 만든다.

## 실내 3D 모델 (.glb) — 2026-10-27 2차

참고 사진 두 장을 기준으로 실내를 직접 모델링해 .glb로 만들었다. 로고·엠블럼 없음, 좌측 운전석.

| 파일 | 참고 | 구성 |
| --- | --- | --- |
| `public/models/cabin-wheel.glb` | 사진 2 | 검정 소프트 대시보드, 가로 우드 트림과 송풍구 슬릿, 떠 있는 가로형 중앙 화면, 원형 2스포크 운전대, 칼럼식 변속 레버, 넓은 센터 콘솔, 페달 |
| `public/models/cabin-driverless.glb` | 사진 1 | 운전대·페달 없음, 짙은 대시보드와 화면 양옆 조명, 크림색 문·뒷좌석 쿠션·컵홀더, 파노라마 유리 지붕, 뒷좌석 시점 |

- 원본은 `cabin-model.mjs`(three.js 코드). 고친 뒤 `npm run dev` 상태에서 http://127.0.0.1:8766/lab/export-cabin.html 을 열면 두 .glb가 내려받아진다. `public/models/`에 덮어쓴다.
- 모양 확인: http://127.0.0.1:8766/lab/cabin-view.html?kind=wheel (또는 driverless)
- 'Screen' 메시는 시뮬레이터가 실시간 속도·거리 화면으로 바꾼다. 반사는 `public/hdri/potsdamer_platz_1k.hdr`(Poly Haven, CC0)를 실내에만 적용한다. 바깥 풍경 색은 바뀌지 않는다.
- 가죽·직물 결은 이미지 파일 없이 코드로 만든 법선 맵이다.
- 실차 .glb를 구하면 같은 이름으로 바꿔 넣을 수 있다. 시점 위치는 `cabin-model.mjs`의 `EYES`에서 맞춘다.
- 저사양 모드: 주소 뒤에 `?quality=low` (반사 끄고 단순 재질). 내장 그래픽에서 끊기면 이 모드를 쓴다.

## 설계 메모

| 결정 | 이유 |
| --- | --- |
| 화면 전체를 React로 옮기지 않고 3D 캔버스만 R3F `createRoot(canvas)`로 렌더링 | 기존 `World` 인터페이스와 퀘스트·회고·전처리 코드를 그대로 쓴다. 바뀌는 범위가 작다. |
| 주행 값은 React 상태가 아니라 `useFrame`에서 직접 갱신, `frameloop: 'demand'` | 0.02초마다 React를 다시 그리지 않는다. 내장 그래픽 노트북 부담을 줄인다. |
| `flat`(톤 매핑 없음) | 기존 three.js 화면과 같은 색을 유지한다. |
| 계기판 글자는 캔버스 텍스처에 시스템 글꼴로 그림 (drei `Text` 미사용) | drei `Text`는 글꼴을 인터넷에서 내려받는다. 학교망·오프라인에서도 동작해야 한다. |
| 실내는 .glb 파일로 분리 | 코드와 모델을 나눠 두면 나중에 실차 모델로 바꾸기 쉽다. |

색(하늘·노면·젖은 노면·잔디·나무·건물·내 차 파랑·앞차 주황)과 움직임(바퀴 회전, 브레이크등, 차간거리 선, 앞차 감속·정지·재출발)은 기존 화면과 같다. `차량 뒤 시점` 버튼으로 이전 외부 시점도 볼 수 있다. 장면 회고의 다시 보기는 차간거리가 잘 보이도록 외부 시점을 쓴다.
