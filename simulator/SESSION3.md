# 3차시: 결과 예상 → 자동 주행 → 장면 분석 → 재학습 · 비교 · 보고서

2026-10-27. 3차시에는 모델 자동 주행만 있었다. 설계 v0.1의 "새 장면 예측, 문제 장면 분석, 기록 추가·재학습, 전후 비교·B 코스, 보고서"를 한 흐름으로 이었다.

```
[주행 설정: model.json 불러오기] ─ 불러올 때마다 모델 1, 모델 2 … 로 보존
        │
        ▼ 출발 버튼
[결과 예상]  ① 고정 장면 3개: 내 예상(Δv 4구간) 먼저 → 모델 값 공개 (모델·노면별 1회)
             ② 이번 주행: 완주/충돌/시간 초과 · 기준 거리 미달 여부 · 이유
        │
        ▼
[자동 주행] (운전대 없는 실내, A 또는 B 코스)
        │ 종료
        ▼
[결과] 결과·주행 시간·최소 거리·기준 미달 시간·가장 강한 감속 제안 + 예상과 비교
        │
        ▼
[장면 분석] 충돌 / 처음 기준 미달 / 최소 거리 / 코스 사건(감속·정지·출발) 중 선택, 앞뒤 3초 3D 재생
            그 순간의 1초 판단: 모델이 본 값 → 모델 제안 → 프로그램 한계 적용 → 1초 뒤 실제 변화
            원인 가설(5개 중) · 기록 근거 · 보완 계획 저장
        │
        ▼
[재학습 · 비교 · 보고서]
   개선용 기록 운전(직접, A 코스, 페달 표시) → 전처리: 2차시 처리 이력 JSON에 이어 붙이기 → train.tab
   → Orange(모델 저장 워크플로) → model-2.json → 불러오기 → 같은 조건으로 A 코스 → B 코스
   비교표: 모델 × 코스 × 노면 × 처음 거리, 같은 조건이 두 모델 이상이면 ● 표시
   보고서 5항목(사람이 한 선택 · 확인한 사실 · 근거 · 개선 범위 · 남은 질문) → session3-result.json
```

## 파일

| 파일 | 역할 |
| --- | --- |
| `course.mjs` | 앞차 코스 A(2차시와 동일)·B(처음 보는 코스). 시각만 보고 움직이며 내 차에 반응하지 않는다. |
| `evaluate.mjs` | 예상 장면·Δv 구간, 결과 요약, 분석 장면, 1초 판단, 비교표, 보고서 완성 판정(순수 함수) |
| `model-session-ui.mjs` | 예상·결과·분석·비교 창 |
| `evaluate.test.mjs` | 위 로직 테스트 10개 |
| `verify-session3.cjs` | 브라우저 전체 흐름 검증 |

## 지킨 원칙 (설계 v0.1)

- 학생이 먼저 고른 뒤에만 모델 값을 공개하고, 공개 뒤에는 예상을 바꿀 수 없다.
- 분석 화면은 저장된 trace만 재생한다. 지금 모델로 과거 주행을 다시 계산하지 않는다.
- 자동 주행 기록은 전처리에서 잠겨 학습 자료에 들어가지 않는다. 개선 자료는 학생이 새로 운전한다.
- 개선용 기록은 A 코스로 고정한다. B 코스는 확인용으로만 쓴다.
- 첫 모델과 개선 모델을 모두 보존하고, 같은 조건끼리만 비교 표시한다.

## B 코스

앞차 25km/h → 3초부터 2.5초 동안 급감속해 정지(약 2.8m/s²) → 8초까지 정지 → 3초 동안 30km/h로 출발 → 16초부터 2초 동안 20km/h로 감속 → 유지.
젖은 노면 상한 40km/h를 넘지 않고, 30초 안에 앞차가 160m 완주 지점을 충분히 지난다(테스트로 확인).
