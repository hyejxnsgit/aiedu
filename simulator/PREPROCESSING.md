# 주행 기록에서 Orange 학습 파일까지

2026-10-27 구현. 화면 오른쪽 위 **전처리 실습**, 또는 **기록 보기 → 전처리하고 학습 파일 만들기**로 연다.

## 학생 사용 순서

1. 서로 다른 주행을 두 번 이상 기록한다. 전처리 화면에서 각각 학습용·검증용으로 배정한다. 같은 주행의 행을 나누지 않는다.
2. 화면의 **결측치**(있어야 할 값이 빠짐, 0과 다름)와 **이상치**(특이한 값, 실제 급감속일 수도 있음) 설명을 읽는다.
3. **다음 확인 필요 행**으로 이동한다. 원본 값·구간 조작 이력·시작/끝 부근 기록을 보고 유지/수정/제외를 결정한다. 이유를 적고 **판단 저장**을 누른다. 복구 근거가 없으면 값을 추측해 채우지 않는다.
4. 전후 건수와 노면 분포를 확인한다. 미해결 후보가 없어야 학습·검증 파일 저장 버튼이 활성화된다.
5. **Orange 학습 파일 저장**, **Orange 검증 파일 저장**으로 .tab 파일을 받는다. Orange의 File에서 열면 입력 4개, 연속형 목표 actual_delta_kmh, 메타정보 run_id/t_s/source가 지정된다. CSV도 별도로 받을 수 있다.
6. **원본·처리 이력 저장**으로 JSON을 받는다. 다음 시간에 위쪽 파일 선택에서 JSON을 열면 원본·판단·주행 배정·취소 이력을 복원한다. 새로고침·탭 종료 전 저장해야 한다.

자동 주행과 1초가 아닌 구간은 원본에는 남고 학습에서 제외된다. 현재 진행 중인 미완료 구간은 전처리 목록에 아직 들어가지 않는다. 주행 종료 후 확인한다.

## 기록이 없을 때 하는 개념 연습

**검토할 자료 → 개념 연습 데이터 (실제 주행 아님)**. 실제 기록에 오류를 섞지 않는다.

| 행 | 확인할 점 | 연습에서 가능한 판단 |
|---|---|---|
| 2 | 거리 빈칸: 결측치 | 실제 값 복구 근거가 없어 제외 |
| 3 | 300km/h: 수업 속도 상한 밖 | 복구 근거가 없어 제외 |
| 4 | −8km/h: 드문 급감속 | 마른 노면 1초 제동 범위 안이므로 이유를 적어 유지 |
| 21 | 5행과 같은 주행·시각 | 중복임을 확인해 제외 |

연습-A를 학습용, 연습-B를 검증용으로 배정하고 위 결정을 하면 **21행 → 제외 3행 → 학습 8행 / 검증 10행**. 파일 이름에 practice가 붙는다. 실제 모델 성능 평가에 쓰지 않는다.

## 개발 검증과 증거

프로젝트 루트에서 다음을 실행한다.

```sh
node --test simulator/motion.test.mjs simulator/drive.test.mjs simulator/review.test.mjs
node simulator/verify-review.mjs
.venv-orange/bin/python simulator/verify-review-orange.py
```

- 계산·전처리 자동 검증 **34개 통과**: 결측치와 0 구분, 물리 범위, 중복, 정상 반복 유지, 원본 보존, 수정/취소, 저장 차단, 주행 분리, CSV 파싱, JSON 복원 등.
- 실제 Orange **3.40.0** 라이브러리로 .tab을 읽어 4개 입력·1개 목표·3개 메타, 8/10행, 주행 중복 없음 확인. `results/review/orange-import-report.json`.
- 브라우저에서 별도 연습 자료 선택 → 주행 배정 → 빈 이유 거부 → 결측/오류/중복 제외 → 급감속 유지 → 다운로드 버튼 활성화 확인. 실제 다운로드한 `practice-train.tab`도 Orange로 읽어 8행 확인.
- 저장한 이력 JSON을 브라우저에서 다시 불러와 배정과 판단 복원 확인. 결측치 행의 처리를 취소하면 다시 저장이 차단되는 것도 확인.
- `results/review/`의 raw CSV·처리 이력 JSON·처리 후 CSV/TAB를 직접 비교할 수 있다. 이들은 명시된 합성 개념 연습 산출물이다.

## 아직 남은 단계

현재는 **같은 주행 ID의 중복 분할**을 방지한다. 시나리오 계열·복제 출처를 추적한 그룹 분할, 별도 A/B 코스, 실제 주행 자료의 하이퍼파라미터 탐색은 다음 단계다. 현재 코스 반복 기록의 검증 점수를 새로운 코스에 대한 일반화 성능으로 해석하면 안 된다.

이상치 통계는 배정된 학습 **원본** 중 형식·물리 검사를 통과한 8행 이상의 실제 변화량에 IQR 기준을 적용한다. 후보 표시용이며 자동 삭제·대체는 하지 않는다. 전처리 완료가 좋은 운전 모델이나 안전성을 보장하지 않는다.

Orange GUI에서 파일 열기부터 Tree 학습·모델 변환·재주행까지의 전체 수업 흐름, 학교 Windows 장비 성능 검증은 아직 남아 있다. CSV는 현재 수업 물리 v0.1로 검사하며 다른 물리 설정의 자료를 가져오면 안 된다. JSON 파일은 학생이 수정할 수 있는 학습 기록이며 위변조 방지 증명서는 아니다.
