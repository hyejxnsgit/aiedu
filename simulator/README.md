## 이전 개발 기록

최신 버전: [3D 가상 운전 시뮬레이터 변경·검증 기록](CHANGELOG-3D.md). 이제 WebGL 3D 도로에서 가속·브레이크를 누르는 즉시 반응하며, 계산 검증은 18개다. 아래 2D·1초 경계 조작 설명은 이전 버전 기록이다.

2026-10-27: 화면과 분리된 단일 차량의 가감속·속도 상한·1초 기록 계산을 구현했다.

실행: 프로젝트 루트에서 `node --test simulator/motion.test.mjs`.

`motion.mjs`는 0.02초 간격 기록을 만들며 정지·상한에 도달하는 시각을 구해 거리를 적분한다. 요청 변화량과 실제 변화량, 제한 이유를 분리한다. 1초 미만 중단은 `complete_interval: false`로 표시한다. 학습 내보내기에서는 이 표시를 사용해 부분 구간을 제외해야 한다.

현재 설정은 설계서의 실험값이다. 실제 차량의 검증된 제동 성능이 아니다.

추가 구현: `drive.mjs`에 두 차량의 상대 운동·구간 내 충돌 검출, 감속/정지/재출발하는 앞차, 1초 기록과 부분 구간 구분을 구현했다. `index.html`과 `app.mjs`는 직접 조작·일시정지·1초 진행·CSV/JSON 저장·변환 모델 JSON 불러오기를 제공한다. 초기 화면은 가벼운 2D 측면 개념도다.

전체 계산 검증: `node --test simulator/motion.test.mjs simulator/drive.test.mjs` — 16개 통과.
